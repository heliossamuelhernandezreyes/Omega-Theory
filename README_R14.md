# Omega R14 — continuidad compartida y estabilidad

Investigación exploratoria **no canónica**, 18 de octubre de 2026. Modelo clásico auxiliar de 3 estados con cantidad redistribuida conservada y colisiones de fotones únicamente como contraste cinemático importado.

## Reproducir

```bash
python scripts/check_shared_continuity_r14.py --out research/data
python -m unittest discover -s tests -p 'test_shared_continuity_r14.py' -v
```

**31 tests locales superados.** Sin librerías externas.

Resultados: `research/ENSAYO_R14_ESTABILIDAD_CONTINUIDAD_COMPARTIDA_V0.md`, `research/data/*.json` y `*.csv`.

**Límite esencial:** estabilidad matemática de un subconjunto bajo una matriz de transición definida no es derivación de materia, masa, gravedad ni tiempo desde la ontología de potencialidad. La formación y el escape permanecen libres.
