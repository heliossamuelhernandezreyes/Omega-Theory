# Roadmap

## Stage 1 — Canon publication

- Publish the navigable canon from the v1.2 master archive.
- Preserve provenance without duplicating the complete frozen archive in normal Git history.
- Connect canonical claims to epistemic labels.

## Stage 2 — Reproducibility

- Select representative numerical experiments from Deliveries 01–21.
- Standardize Python environments and entry points.
- Add lightweight automated checks for algebraic identities and numerical tolerances.
- Document which large datasets are generated rather than versioned.

## Stage 3 — Delivery 22

Study whether an action can be defined from ordinal or relational precedence without assuming fundamental time. Test refinement invariance, additivity, and whether the action scale is fixed or remains a calibration freedom.

## Stage 4 — Physical bridge

- Define operational observables.
- Derive testable limits and parameter maps.
- Compare with established gravitational, cosmological, thermodynamic, and quantum constraints.
- Identify at least one prediction that distinguishes Omega Theory from its reference models.

## Stage 5 — Public scientific release

- Choose explicit licenses.
- Prepare a reproducible release archive.
- Write a concise technical manuscript separating ontology, formalism, numerical results, and phenomenology.
