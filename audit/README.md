# Evidencia de auditoría

`reports/` contiene los informes de las Fases 0–4. `coverage/` contiene el denominador final, la matriz archivo por archivo y los manifiestos. Las matrices semánticas se publican en las carpetas temáticas del repositorio para evitar duplicación.

El estado original se conserva sin reescritura en `ESTADO_AUDITORIA.json`: la cobertura técnica estaba demostrada y el acta preparada, pero el cierre formal separado permanecía pendiente de aprobación al generar el paquete.

El paquete completo de evidencias, incluidos logs y clasificaciones masivas no convenientes para Git, se preserva como asset externo por SHA-256.
