`ontología -> consecuencias necesarias -> formalización -> derivación -> prueba/falsación -> predicción congelada -> comparación observacional`.

No se identifica potencialidad con probabilidad, energía, entropía o cardinalidad por conveniencia.

## Fase 81 — potencialidad, saturación y relevancia futura

La candidata auditada fue la potencialidad efectiva entendida estrictamente como estructura de continuaciones compatibles accesibles.

### No-go 81-A

Alta o creciente accesibilidad puede coexistir con un invariante histórico preservado que siga alterando todos los futuros. Por tanto:

`alta accesibilidad != memoria corta`.

### No-go 81-B

Dos estados pueden tener soporte inmediato relacionalmente isomorfo y, sin embargo, futuros completos distintos a profundidad mayor.

`igual soporte de un paso != equivalencia futura completa`.

### No-go 81-C

Soporte local constante tampoco implica finitud de `S_F`: una marca genealógica puede controlar recursivamente la estructura futura manteniendo igual número local de continuaciones.

### No-go 81-D

La ley `R(u)=exp(-su)` no actúa por sí sola sobre `S_F`, invariantes históricos o tipos futuros. No deriva olvido, mixing ni saturación predictiva.

### Teorema condicional 81-E

Si existe saturación uniforme de **tipos futuros**, de modo que después de una profundidad `N` ciertos invariantes históricos ya no puedan producir futuros no isomorfos, entonces dichos invariantes pueden eliminarse del estado predictivo después de `N`.

Esto produce memoria efectiva acotada respecto de ellos.

La condición es suficiente, pero no está derivada.

## Distinción conceptual

Omega debe distinguir:

1. saturación de una respuesta escalar;
2. saturación/estabilidad del soporte local;
3. saturación predictiva de tipos futuros.

Sólo la tercera implica contracción histórica. No se ha derivado `1 -> 3` ni `2 -> 3`.

## Veredicto

La potencialidad como accesibilidad es demasiado débil para imponer borrado causal.

El esquema permanece:

`historia -> S_F -> soporte cerrado -> [saturación de tipos futuros NO derivada] -> memoria efectiva corta`.

## Estado epistemológico tras Fase 81

### Derivado

- alta accesibilidad no implica memoria corta;
- soporte inmediato igual no implica futuro completo igual;
- soporte local constante no implica cierre finito;
- respuesta exponencial no implica saturación predictiva.

### Condicional

- saturación uniforme de tipos futuros basta para borrar relevancia de invariantes excluidos.

### No derivado

- saturación predictiva universal;
- horizonte universal de olvido;
- contracción de `S_F`;
- mixing/ergodicidad;
- probabilidad;
- dinámica única.

## Cuello de botella actualizado

El problema ya no puede resolverse identificando potencialidad con “cantidad de opciones” o con una respuesta que satura. Hace falta una razón estructural para que la composición de futuros vuelva irrelevante parte de la genealogía.
