# Archaeology — Phase 19

The canonical/historical material contains qualitative language about identity persistence, bifurcation/fusion, relational inertia, and support/cost of reorganization, but no closed numerical law for the edit support required to change a stable identity class.

Phase 18 explicitly left open whether exact extensivity survives once the coarse-graining itself changes. Phase 19 therefore treats the stable fixed-point partition as the target object and measures exact graph-edit distance to a partition-changing boundary.
