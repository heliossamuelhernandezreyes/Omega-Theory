# Manifest — Phase 19

Status: experimental, non-canonical.

Question: minimum number of compatibility-relation edits required to change the Phase-12 stable fixed-point equivalence itself.

Domain: all 4096 directed simple graphs on four labeled nodes; all six unordered node pairs.

Definitions: `S_split` is minimum Hamming distance to a graph where an initially equivalent pair becomes inequivalent; `S_merge` is the converse. `S_partition` is the minimum Hamming distance to any graph with a different fixed-point partition.

No observational data, probabilities, energies, masses, or fitted constants introduced.
