# Manifest — Phase 20

Status: experimental, non-canonical.

Question: which structural observables, if any, predict the exact pair-splitting critical support S_crit from Phase 19?

Domain: all 4096 directed simple graphs on four labeled nodes; all node pairs belonging to the same Phase-12 stable class. Total pair-instances: 15924.

Predictors: stable block size; |Aut(Gamma)|; pair automorphism equivalence; shared SCC; refinement iterations; symmetric count of directed walks of lengths 1..3 between the pair.

No observational data, probabilities, fitted physical constants, energy, mass, or causal interpretation of correlations.

Principal result: no tested scalar invariant uniquely determines S_crit. Short-walk redundancy has the strongest tested association (Pearson 0.536574; Spearman 0.458637) but admits counterexamples at fixed redundancy.
