# Manifest — Fase 34

Estado: investigación nueva / no canónica.

Pregunta: ¿puede definirse una longitud de trayectoria invariante bajo agrupación de pasos?

Objetos:
- distancia neta `D_end`;
- soporte ejecutado `W`;
- exceso redundante `R=W-D_end`.

Resultado: `D_end <= W`; `inf W = d_H` entre endpoints; `W` es invariante bajo agrupación sólo si los macro-pasos heredan la suma del soporte microscópico representado.

No se interpreta `W` como energía ni masa.
