# Fase 69 — Profundidad predictiva vs geometría

Esta fase prueba si `d_*`, derivada independientemente en Fases 64–66, reduce la subdeterminación geométrica introducida en Fases 67–68.

Orden documental obligatorio:

1. `PREREGISTRATION.md` — pregunta, dominio, observables y criterios fijados antes de ejecutar.
2. `code/predictive_depth_geometry.py` — productor determinista sin dependencias externas.
3. `results/summary.tsv` — resultados exactos del dominio exhaustivo.
4. `results/counterexamples.tsv` — pares de geometrías distintas que comparten `d_*`.
5. `REPORT.md` — interpretación posterior, separada de los datos.

No se permite editar el prerregistro para acomodarlo al resultado. Una variante posterior debe abrir una fase o subfase nueva y declarar qué cambió.
