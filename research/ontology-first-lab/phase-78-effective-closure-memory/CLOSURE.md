# FASE 78 — CIERRE

> ESTADO: CERRADA / INVESTIGACIÓN NO CANÓNICA

## Resultado central

La equivalencia futura `~F` induce una relación bien definida entre clases de `S_F`, de modo que el **soporte de posibilidades** se cierra a primer orden sobre el estado futuro-equivalente actual.

Esto no convierte a Omega en un proceso de Markov probabilístico: no existe todavía una medida, kernel físico ni ley de realización derivada.

## Teoremas / no-go

1. `~F` es congruente con la extensión en el sentido de que futuros isomorfos inducen patrones equivalentes de clases sucesoras.
2. Existe una relación cociente `->_F` sobre `S_F`.
3. Existe representación finita exacta del tipo futuro iff `|S_F|<infinity`.
4. Índice finito no implica memoria de ventana finita.
5. La ontología actual admite contramodelos con `|S_F|=infinity`.
6. La ontología actual admite contramodelos en los que ninguna ventana histórica uniforme `k` basta para determinar la clase futura.
7. Continuidad/composición vigentes no fuerzan olvido de memoria, mixing, contracción ni finitud.

## Veredicto

- cierre estructural de soporte: DERIVADO;
- estado finito universal: NO DERIVADO / REFUTADO COMO CONSECUENCIA NECESARIA;
- memoria de ventana finita universal: NO DERIVADA / REFUTADA COMO CONSECUENCIA NECESARIA;

- dinámica única: NO DERIVADA.
