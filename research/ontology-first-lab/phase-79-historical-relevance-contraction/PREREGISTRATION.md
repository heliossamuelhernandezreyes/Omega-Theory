# FASE 79 — PRERREGISTRO

> ESTADO: INVESTIGACIÓN NUEVA / NO CANÓNICA

## Pregunta

¿Continuidad, composición, identidad genealógica o accesibilidad obligan a que diferencias históricas antiguas pierdan relevancia para la estructura de futuros admisibles, de modo que historias inicialmente distintas terminen cayendo en la misma clase futura `S_F` tras suficiente extensión?

## Fuente permitida

1. Historias ontológicas y extensión estricta.
2. Accesibilidad/compatibilidad de continuaciones.
3. Cociente futuro `S_F = Hist/~F` de Fase 77.
4. Cierre de soporte `->_F` de Fase 78.
5. Continuidad y composición sólo en los sentidos ya derivados; no reinterpretarlas como disipación o mezcla.

## Prohibido

- entropía o coarse-graining introducidos para forzar olvido;
- ruido, decoherencia o disipación;
- probabilidad, mixing o ergodicidad;
- localidad o horizonte causal espacial;
- ventana de memoria finita asumida;
- pérdida de información por decreto;
- identificación de `R(u)=exp(-su)` con decaimiento de memoria.

## Definiciones de prueba

Sean `s,t in S_F` clases futuras distintas.

- **Fusión posible:** existen extensiones admisibles `s ->*_F u` y `t ->*_F u` hacia una misma clase futura `u`.
- **Contracción universal eventual:** existe una cota o mecanismo ontológicamente forzado que hace que toda distinción suficientemente antigua deje de cambiar el tipo futuro.
- **Distinción persistente:** existe un par de historias/clases que permanece futuro-distinto bajo toda extensión relevante compatible.

## Hipótesis congeladas

### H0 — no hay contracción universal derivada

La ontología permite tanto sistemas con fusión/olvido como sistemas con memoria histórica persistente; por tanto no selecciona contracción universal.

### H1 — contracción necesaria

Continuidad/composición/historia fuerzan que toda diferencia suficientemente antigua pierda relevancia.

### H2 — persistencia necesaria

La identidad genealógica impide toda fusión futura de clases `S_F` distintas.

## Pruebas

1. Determinar si clases distintas de `S_F` pueden tener sucesores equivalentes.
2. Construir un modelo admisible con fusión de relevancia histórica.
3. Construir un modelo admisible con una marca relacional histórica persistente que siga afectando accesibilidad arbitrariamente lejos.
4. Identificar condición suficiente para persistencia.
5. Identificar condición suficiente para fusión/sincronización.
6. Auditar si continuidad o `R(u)=exp(-su)` añaden alguna de esas condiciones. Si no, registrar no-go.

## Criterio de cierre

Sólo se declarará pérdida ontológica de memoria si aparece como consecuencia necesaria de las premisas vigentes. La mera existencia de ejemplos que olvidan no cuenta como derivación universal.
