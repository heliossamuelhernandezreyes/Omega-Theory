# FASE 81 — CIERRE

> ESTADO: CERRADA / INVESTIGACIÓN NO CANÓNICA

## Resultado central

La potencialidad entendida como accesibilidad compatible no contiene por sí sola una ley de olvido histórico.

Se refutan las implicaciones universales:

- alta accesibilidad -> memoria corta;
- soporte local constante -> memoria corta;
- respuesta exponencial -> saturación predictiva;
- saturación de respuesta -> contracción de `S_F`.

## Condición suficiente identificada

La propiedad relevante es la **saturación uniforme de tipos futuros**: después de una profundidad finita, ciertos invariantes históricos dejan de poder producir futuros no isomorfos.

Bajo esa condición aparece memoria predictiva acotada respecto de dichos invariantes.

Pero esa propiedad no está derivada de la ontología vigente.

## Veredicto

`potencialidad = accesibilidad` es estructuralmente demasiado débil para imponer borrado causal.

No se promueve saturación predictiva al canon.
