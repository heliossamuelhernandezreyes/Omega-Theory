# Fuentes primarias seleccionadas

Esta carpeta contiene documentos primarios necesarios para resolver las 20 afirmaciones nucleares sin duplicar los 22 paquetes completos. Se conservan byte a byte y mantienen la jerarquía interna posterior al nombre del paquete.

El resto de las fuentes primarias permanece en el ZIP maestro. La selección no eleva su estado epistemológico; sólo las hace navegables.
