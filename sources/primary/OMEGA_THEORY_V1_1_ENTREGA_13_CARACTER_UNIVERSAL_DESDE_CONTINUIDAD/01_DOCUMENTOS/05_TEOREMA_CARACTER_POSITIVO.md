# Teorema condicional del carácter positivo

Sea \(R:\mathbb R\to\mathbb R_{>0}\) una función continua tal que:

\[
R(0)=1,
\]

y:

\[
R(u+v)=R(u)R(v).
\]

Entonces existe \(s\in\mathbb R\) tal que:

\[
R(u)=e^{-su}.
\]

## Interpretación Omega

Toda respuesta local positiva, continua y composable del campo de actualización debe ser exponencial.

## Consecuencia ontológica

Para todo \(u\) finito:

\[
R(u)>0.
\]

Por tanto, la continuidad puede volverse operacionalmente inaccesible sin anularse exactamente.
