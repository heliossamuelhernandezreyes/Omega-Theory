# Teorema condicional generador–energía

Sea \(\omega\ge0\) un generador continuo y aditivo para modos independientes. Sea \(E(\omega)\) una energía continua, extensiva y nula para \(\omega=0\).

Entonces:

\[
E(\omega_1+\omega_2)=E(\omega_1)+E(\omega_2)
\]

implica:

\[
\boxed{
E(\omega)=\kappa_\Omega\omega.
}
\]

El teorema fija la forma funcional, no la constante \(\kappa_\Omega\).
