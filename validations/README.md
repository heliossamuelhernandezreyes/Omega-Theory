# Validaciones y reproducción

Esta carpeta registra qué código se ejecutó, bajo qué entorno, con qué adaptación y qué resultado produjo.

- `CODE_COVERAGE.csv`: las 40 ocurrencias de Python.
- `CODE_EXECUTIONS.csv`: 28 ejecuciones por hash único.
- `REPRODUCTION_SUMMARY.json`: conteos y reservas.
- `AUDIT_ENVIRONMENT.json`: versiones observadas.
- `DETERMINISM_SUMMARY.json`: repeticiones exactas disponibles.
- `DEPENDENCY_RETRIES_SUMMARY.json`: controles limitados tras fallos de dependencia.

La validación física externa está fuera del alcance demostrado.
